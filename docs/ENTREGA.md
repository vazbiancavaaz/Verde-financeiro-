- [x] Código-fonte Python organizado e executável.
- [x] README em português com objetivo, tecnologias, execução e espaço para integrantes.
- [x] `requirements.txt` com dependência externa Flask.
- [x] `.gitignore` para caches, ambientes virtuais, segredos e bancos pessoais.
- [x] Interface web local, dados persistentes e testes automatizados.
- [x] Instruções de Git e GitHub.
- [ ] Preencher os integrantes no README.
- [ ] Instalar Python e Flask no computador de apresentação.
- [ ] Executar o aplicativo no Chrome e conferir os formulários.
- [ ] Criar o repositório GitHub, enviar os arquivos e conferir o link em janela anônima.
- [ ] Verificar `git status` e garantir que nenhum dado pessoal foi incluído.

**Importante:** o guia GFT pede código, README e `.gitignore`; `requirements.txt` é necessário aqui porque Flask é uma dependência externa. Publicação no GitHub depende da pessoa que possui a conta.
